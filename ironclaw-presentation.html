Channels

The Channel Trait

pub trait Channel: Send + Sync {
  fn name(&self) -> &str;
  fn start(&self) -> Pin<Box<dyn Stream<IncomingMessage>>>;
  fn respond(&self, msg: OutgoingResponse) -> Result<()>;
  fn send_status(&self, status: AgentStatus);
  fn update_secrets(&self, secrets: SecretMap);
}

ChannelManager merges all channel streams into a single async stream. Adding a new channel: implement the trait, add config, wire in app.rs.
